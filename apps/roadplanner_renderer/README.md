# Roadplanner Renderer (PoC)

**Experiment. Kein Produktfeature.** Diese App beweist ausschliesslich, dass
Roadplanner und eine separate Home-Assistant-App zuverlaessig zusammen
arbeiten koennen. Sie enthaelt **kein Remotion, keinen Browser und keinen
Videoexport**.

Roadplanner funktioniert ohne diese App vollstaendig. PDF-Export und die
bestehende ffmpeg-Videopipeline sind davon nicht beruehrt.

Details, Kommunikationsvertrag und Berechtigungen: siehe `DOCS.md`.
